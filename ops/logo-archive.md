# 로고 아카이브와 대표 이미지

- 브랜드 콘텐츠: `semologo.logo_posts` (기존 ID/URL 유지).
- 로고 자산 이력: `semologo.logo_versions` (브랜드 1 : 버전 N).
- 대표 노출 선택: `logo_posts.payload.presentation = {file, bg}`. 로고 버전과 분리한다.
- 도입/종료 연도는 출처가 확인될 때만 입력한다. 수집·확인 날짜에서 연도를 추정하지 않는다.
- `version_kind`: 기존 자산 등록 / 자산 검수·수정 / 실제 브랜드 리뉴얼. 변환 오류 수정은 리뉴얼이 아니다.
- `is_current`: 현재 서비스가 제공하는 자산 버전. 브랜드 공식 최신 로고 여부를 자동으로 보증하지 않는다.
- `review_status`: pending / verified / rejected. 미검수 이력은 다운로드 링크를 표시하지 않는다. 연도·출처 편집만으로 자산 검수 상태를 승격하지 않는다.
- 동일 자산 스냅샷은 중복 버전을 만들지 않는다. 브랜드마다 현재 버전은 정확히 하나다.
- 기존 원본은 덮어쓰지 않는다. 새 검수 SVG/PNG는 날짜·해시가 있는 별도 경로에 게시한다.
- 자산 필드 변경을 DB 트리거가 기록한다. 배경·대표 파일 선택과 게시 상태 변경은 로고 변경 이력을 만들지 않는다.
- 수집 파이프라인은 업로드 바이트 검증 후 현재 버전에 파일 SHA256·매니페스트·출처·검수 상태를 기록한다.
- 관리자: 상세 화면에서 파일+밝은/어두운 배경 선택 → 대표 지정. 아카이브에서 연도/근거 URL/검수 메모/이력 구분 관리.
- 공개: 아카이브의 도입 연도, 수집 날짜, 현재 제공/이전 수집본, 검수한 원본 파일과 출처.
