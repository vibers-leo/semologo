# 세모로고 대용량 SVG 수집 계약과 다음 두 PC 명부

2026-10-15. 직전 작업에서 공식 사이트 SVG 11개가 20KB 원본 제한만으로 보류됐다. 다시 받은 원본은 25,207~111,041바이트이며 gzip 후 7,516~28,926바이트여서 65KB 결과 JSON 안에 담을 수 있다. 11개 모두 원본 SHA-256을 고정하고 `semologo-cycle-20261015c`로 재검증했다. win01의 국내 기관 CI 영역이다. win02의 다음 기업 사이트 영역으로 20개 URL도 별도 명부 `semologo-cycle-20261015d`에 사전 검증했다. 양쪽 모두 수집 후보이며 공개 콘텐츠 확정 수가 아니다.

공유 fleet의 세모로고 수집기만 원본 150KB, gzip 본문 45KB까지 받아들이도록 확장했다. 20KB 이하 원본은 기존 `originalBase64` 형식을 유지하고 큰 원본에는 `originalGzipBase64`와 `originalBytes`를 쓴다. 서버는 압축 데이터의 정규 base64, 150KB 압축 해제 상한, 원본 길이, SVG 시작 내용, SHA-256, 출처 변경 여부를 재검증한다. 버킷 결과 JSON은 기존 65KB 상한과 비공개 경로를 유지한다. 로컬 회수 스크립트도 해제 길이를 제한하며 SHA-256을 다시 확인한다. 수집 후 시각·신원·SVG 안전 검토 전에는 공개하지 않는다.

서버는 기존 공유 이미지 위에 수집기·검증기·79개 출처 명부만 덧입힌 `vibers-fleet:20261015-semologo-gzip-r23`이다. 배포 전 현행 이미지와 명부 해시를 확인하고 이전 컨테이너를 보존했다. 배포 뒤 `check-deploy.sh`가 running, restarts 0, HTTP 200, DEPLOY OK를 반환했다. Windows handoff는 최신 `20261015-keyen-utf8` 패키지를 기준으로 세모로고 수집기·검증기·명부·버전만 교체해 다른 프로젝트 파일을 보존했다. 새 ZIP SHA-256은 `94a617ba0c0c0f8f97c7b9925e9a10103c8f831907520a487c750c96ad760c92`, 비공개 버킷 업로드 및 읽기 검증 후 중앙 `current.json`에 게시했다.

워커 적용과 실제 수집 결과는 `marketing/assets/worker-logo-cycle-20261015c/`의 진단·manifest·audit에 별도로 기록한다. 아래 단계는 진단에서 두 PC가 r23을 보고한 뒤에만 진행한다.

두 PC 모두 r23을 진단에서 보고했다. win01의 11건 중 8건을 수집해 버킷 결과·원본 해시를 재검증했고 3건은 처리 실패였다. 실패한 3건을 win02에서 다시 시도했으나 동일하게 실패해 Windows 경로의 출처별 문제로 남겼다. Mac에서 같은 URL을 다시 받아 원본 해시 일치를 확인했다. 해당 Mac 원본은 워커 성공 건으로 계상하지 않는다. 안전·렌더 검사를 통과한 워커 원본은 6건이다. KIAS고등과학원과 경기평택항만공사의 SVG는 포함 콘텐츠 때문에 보류했다.

국립중앙의료원(`gongu-ci-0980`), ECO융합섬유연구원(`gongu-ci-0137`), 국민권익위원회(`gongu-ci-0987`)는 기존 PNG와 공식 SVG의 같은 형태를 화면으로 비교했다. 각 기존 PNG를 두 번째 구성으로 남기고 공식 SVG·1200px PNG를 첫 번째 구성으로 게시했다. CMS 현재 버전 구성 3/3, 공개 상세 페이지와 이미지 GET 200을 검증했다. 신규 브랜드 수는 늘지 않는다. 우체국물류지원단과 KDI국제정책대학원은 앞서 수집한 공식 구성에 같은 형태가 있어 중복 추가하지 않았다. Mac fallback의 우체국금융개발원 원본도 `posid` 콘텐츠에 이미 같은 해시가 있다. 경남투자경제진흥원 SVG 두 개는 보이는 배경 요소 때문에 교체 검토 대상으로 유지한다.

다음 win02 기업 영역 20건은 `semologo-cycle-20261015d`로 사전 검증했다. 밝은·어두운 배경 미리보기를 검토해 일부는 배경 전용 또는 심볼 단독임을 확인했으며, 공개는 각 기업 신원과 라이브 중복 여부를 다시 확인한 뒤에만 한다. 공유 fleet 서버가 다른 프로젝트의 `20261016-keyen-validator`로 갱신된 것을 확인하고 그 이미지를 기반으로 99개 출처 명부만 덧입혔다. 기존 handler 파일 해시를 보존했고 배포 점검은 running, restarts 0, HTTP 200, DEPLOY OK다. Windows 패키지도 최신 `20261015-keyen-stages` 패키지를 바탕으로 명부와 버전만 바꿔 비공개 버킷 읽기 검증 및 중앙 게시를 완료했다. ZIP SHA-256은 `dea10baf00a57005820a6aab4a40ed17db5466c6e983a93d7e02b24357eb9916`이다.
