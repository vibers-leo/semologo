## 판단 기준

세계 전체를 포괄하는 객관적 로고 서비스 순위는 확인되지 않았다. 경쟁사의 자체 광고 숫자를 동일한 검수 브랜드 수로 취급하지 않는다. Logo.dev는 1억 브랜드 모니터링, Brandfetch는 5천만 브랜드를 안내한다. API 조회 가능 도메인과 직접 SVG/PNG 다운로드·검수 브랜드는 다른 지표다. 이를 이유로 목표를 몰래 축소하지 않으며, 총량·품질·사용성·유입을 각각 비교하고 입증되지 않은 세계1위 문구는 쓰지 않는다.

2026-10-11 공개 /api/catalog/?limit=1 응답 total=181761. 이는 공개 카탈로그 항목 수이며 고유 브랜드·PNG/SVG 실물 검수 수는 아니다. /en/ 타이틀과 ko/en/x-default hreflang 존재 확인. 해외 유입·다운로드 전환·국가별 RPM은 미측정.

첫 실물 표본: 기본 인기순 상위30항목, PNG 디코딩30/30·투명영역 존재26/30·SVG를 제공한다고 표시한28개 모두 바이트/래스터포함검사 통과(나머지2개 PNG전용). 비무작위 작은 표본이며 전체품질의 추정치나 공식신원 검수 완료가 아니다. 자세한 개별결과는 `ops/evidence/growth-quality-baseline-20261011.json`. 흰색 후보는 수동 검수하며 자동 제거하지 않는다.

선두권 비교: Seeklogo·Worldvectorlogo·Logowik와 동일한 30브랜드/6사용 과제를 먼저 고정해 비교한다. 공식 심볼 찾기, SVG 받기, 투명PNG 받기, 과거버전 구분, 로고월 만들기/이식하기, 없는로고 요청하기. 제공 여부·정확성·작업 완료 시간·막힌 단계 기록. 로그인 필요·유료조건도 기록한다. 선정 비교군에서의 우위만 주장하며 세계전체 순위로 일반화하지 않는다. 다른 서비스의 자산을 무단 대량 복제하지 않는다.

### 제안하는 주간 제품 기준 (미확정 숫자)

- 인기·요청 우선 1000항목 실물 검수: 중복·잘못된 매칭 제외, PNG HTTP/디코딩·SVG 실제 벡터·해상도·흰 배경·여백·현재/과거 버전 기록. PNG 정상 제공 목표99% 이상, SVG 제공 표시는 실물 확인100%. 검수 전 기준값은 미측정. 1000 전체를 확인하지 않으면 표본이라고 보고한다.
- 구단 명부 5세트(KBO·KBL·NBA·MLB·K1) 기준일/전체대상/매칭/파일검수/제공/누락을 각각 공개. 마스코트·기업 스폰서·B팀은 다른 신원. 목표는 세트 완결성이고 신규 파일 수 경쟁이 아니다. 원본 없는 항목은 누락 사유 표시.
- 로고월 첫 사용자 5명 테스트: 검색→선택→개별크기→재생→저장→ZIP→압축해제→오프라인HTML. 실제 PNG·SVG(있는 것)·HTML/CSS/JS·JSON·OG·README 제공 내용 대조. 성공5/5를 내부 시나리오 목표로 제안하며 전체 사용자의 전환율로 주장하지 않는다.
- 요청/제보: 로그인·비로그인 허용 범위, 중복/변형 연결, 접수번호·진행상태, 관리자 검수→게시→신청자 확인의 종단 검증. 자동 발송 실테스트는 하지 않는다.

## 해외 트래픽

1. 기존 /en/ 재사용. brand+logo SVG, transparent PNG, symbol, logo history 검색 의도별 검수 콘텐츠; 제목만 번역하는 대량 빈 페이지 금지. 영문명이 ID인 브랜드부터 정정·별칭 보강.
2. 해외용 세트: Korean brands / K-pop entertainment / Korean universities / KBO teams; NBA·MLB 등 글로벌 수요 세트. 1세트에 기준일·누락·파일형식·원본출처·사용법 제공.
3. 로고월 템플릿: partners/sponsors, tech stack, client logos. 자기 저장소에서 동작하는 ZIP과 코드로 개발자 유입. GitHub 예제·Figma 자료·디자인 커뮤니티 소개는 초안 준비 후 채널별 규칙·발행 권한 확인; 무단 게시하지 않음.
4. 공유용 OG와 공개 로고월은 소유자 공개 동의를 반영. 선택적 출처 링크를 제안하되 파일에 강제 워터마크를 넣지 않음.
5. 국가·언어·검색어·랜딩·다운로드·로고월 저장/내보내기 연결. Search Console 색인/클릭·GA 세션·서버다운로드는 다른 분모. 해외 세션비중만 늘려 성공이라 하지 않고 해외 유효 다운로드와 반복사용을 본다. SEO 순위/수익 상승은 7일 내 보장 불가.

## 세모위키 숏폼

포지셔닝: ‘재미있는 로고 실험을 보고, 실제 디자인에 바로 써보는 채널’. AI 재해석은 비공식 실험으로 명시, 공식 파일과 혼합하지 않는다. 역사/뜻은 공식근거를 찾은 뒤 대본에 반영한다. 조회수만 아닌 유효방문→다운로드/로고월 전환을 측정한다.

시리즈: AI가 다시 만든다면 / 바뀌기 전후 / 로고 속 디테일 / 15초 활용법. 한국어 원본+영문 자막/제목 실험, 같은 영상을 무분별하게 복제 게시하지 않는다. 제안 첫 묶음7개: 현대자동차 AI 재해석, 한국 자동차5개 AI 재해석, 최소 선으로 다시 만든 브랜드, 1990년대 감성 네이버 가상안, 스포츠팀 엠블럼 비교, 로고월30초 완성, SVG와PNG 확대 비교. 사실 확인이 필요한 이야기는 검수대기.

첫 편 35초 초안: 0~3초 ‘현대자동차 로고를 AI가 다시 만든다면?’ → 3~7초 실제 원본 제시 → 7~23초 미래형/복고형/초미니멀 가상안3종(항상 AI 비공식 표시) → 23~29초 ‘어떤 안이 가장 현대다워 보이나요?’ → 29~35초 실제 세모로고 화면에서 원본SVG/PNG와 로고월 활용 → ‘원본 파일과 로고월은 프로필 링크에서’. 아직 영상·가상안 생성/업로드 미실행.

Shorts 설명/댓글 외부URL은 클릭되지 않으므로 ‘고정댓글 링크’만 CTA로 쓰지 않는다. 채널 프로필 링크 또는 Shorts 관련영상(YouTube 내부)을 이용하고 관련 사용법 영상의 설명에서 사이트로 이동. 프로필 UTM은 source=youtube, medium=social, campaign=semowiki_launch; Shorts→프로필 경로만으로 개별 영상 유입을 정확하게 식별했다고 하지 않는다. 영상별 별도 랜딩/캠페인 링크나 내부 관련영상으로 측정 범위를 명시한다.
