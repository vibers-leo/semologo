## 수집 완료 판정
공식 명부 스냅샷 → 브랜드 매칭 → 로고 검수 → PNG 생성 → CDN 응답/디코딩 확인 → CMS 공개 → 프론트 표시 확인.
QID·도메인 일치만으로 자동 병합하지 않는다. 같은 브랜드 변형은 자산으로 연결하며 자회사·서비스는 별도 엔터티를 유지한다.

## 연관 관계
- 변형: 동일 브랜드의 가로형·세로형·심볼·색상 버전. 브랜드 관계 테이블 대신 자산 변형으로 저장.
- 그룹: 모회사·자회사. 방향과 근거 기록.
- 행정: 시도·기초단체·행정구 소속. 법적 유형과 기준일 기록.
- 컬렉션: 기준일 목록에서 공동 구성원. 일반 연관 관계로 복제하지 않고 membership으로 조회.
- 업종 추천: 분류 기반 추천. 법적 소속 관계로 표현하지 않는다.

## 로고월 지속성
우리 CDN URL만 연결하면 서비스 중단 시 이미지가 사라질 수 있다. 저장된 자산 버전과 다운로드 패키지를 제공하고 API/MCP 소비자는 자신의 저장소에 복사할 수 있게 한다.
