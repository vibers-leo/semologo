# 공식 로고 수집과 구성 검수 기준

PNG는 모든 검수된 구성의 기본 다운로드다. SVG는 실제 벡터 원본을 확보하고 렌더링을 확인했을 때 함께 제공한다. PNG를 SVG에 감싸 벡터로 표시하지 않는다.

## 수집 범위

공식 CI 페이지의 심볼마크, 레터마크, 국문·영문 로고타입, 시그니처와 매뉴얼을 함께 확인한다. 대표 한 개만 추출하고 끝내지 않는다.

- 심볼마크와 레터마크는 별개 구성이다.
- 국문/영문/국영문 각각 좌우조합과 상하조합을 확인한다.
- 심볼 기반과 레터마크 기반 조합을 각각 보관한다.
- 실제 공식 구성만 제공한다. 없는 조합을 임의로 재배치하지 않는다.
- 누락된 구성은 없다고 단정하지 않고 재수집 대기 목록에 남긴다.

## 데이터

`lockup`은 심볼·이름의 위치(horizontal/vertical) 또는 독립 마크(symbol/lettermark/wordmark)를 기록한다. `text_layout`은 텍스트 내부 언어 배열, `mark_type`은 조합에 사용된 마크 유형을 기록한다. 화면 이름은 국문 좌우조합, 영문 좌우조합, 국영문 좌우조합, 국영문 상하조합처럼 사용자가 구분할 수 있게 지정한다.

## 검수

매뉴얼의 캡션·격자·옆 구성은 포함하지 않는다. 도형 전체 경계와 글자 하단을 확인하고 투명 여백을 남긴다. 각각 PNG로 렌더한 뒤 전체 구성표를 육안 확인한다. 흰색 도형을 일괄 제거하지 않는다. 원본, 추출 범위, 파일 해시, 공식 출처를 보관한다. SVG/PNG CDN 파일과 공개 화면을 배포 후 확인한다.

## 서비스

로고 구성은 큰 미리보기와 구성 이름, 해당 SVG/PNG 다운로드로 제공한다. 다운로드 파일은 대표 로고의 용도별 가공본이다. 실제 세로조합이 있으면 메인에 우선 사용하되 관리자 수동 선택은 존중한다. 로고월에서는 각 구성을 독립적으로 선택한다.
