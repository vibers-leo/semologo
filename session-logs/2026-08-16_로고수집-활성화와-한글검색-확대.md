## 왜 수집이 0건이었나 — 고장이 아니라 포화

Simple Icons·Font Awesome·위키미디어 카테고리는 **이미 다 가져왔다.**
수백 개를 새로 얻으려면 소스 자체가 바뀌어야 한다.

새 소스: **위키데이터 '국가=대한민국 + 공식로고(P154)'** — 971개 중 미보유 657개.
우리 차별점(한국 브랜드·한글 검색)과 정확히 겹친다.

## 함정 5가지 (전부 실측으로 잡음)

### ① 이름 검색 1등을 믿으면 15건 중 5건이 오답이다
```
neptune.ai → 해왕성    Glide → 반모음    ChatBot → 채터봇
Capacitor  → 축전기(전자부품. Ionic Capacitor 가 아니다)
```

→ 위키데이터 항목의 공식 웹사이트(P856)가 우리 도메인과 같을 때만 반영.
   같은 표본에서 오답 0건.

### ② 도메인 비교는 등록가능 도메인(eTLD+1)으로
전체 호스트로 비교하니 `support.trustpilot.com` 이 불일치로 떨어졌다.

### ③ `.kr` 만 통과시키면 진짜 한국 브랜드를 버린다
하나은행(hanabank.com)·채널A·아리랑·두산에너빌리티 등 **334개**.
외국 국가코드만 뺀다.

### ④ 파일명이 겹치기만 하면 안 된다 — 대조 시트로 잡았다
`롯데하이마트` 에 **"Lotte Mart 2018.svg"** 가 붙어 있었다(위키데이터 쪽 오류).
`lotte` 하나가 겹쳐서 가드를 통과했다. 여러 브랜드에 공통으로 나오는 단어는
근거로 치지 않도록 고쳤다.

**렌더해서 눈으로 안 봤으면 그대로 배포됐다.** 같은 검수에서 중복도 나왔다 —
kcc-glass = kcc-engineering, 성모병원 5개 분원이 동일 파일.

### ⑤ 위키데이터 라벨은 브랜드명이 아니라 문서 제목이다
```
AMD  → "어드밴스트 마이크로 디바이시스"   (아무도 이렇게 안 부른다)
KBS  → "KBS (한국방송공사)"              (괄호가 그대로)
JTBC → "JTBC 뉴스룸"                    (프로그램 이름)
```
→ **표시 이름은 건드리지 않고 별칭(aliases)에만 넣는다.**
   목록(brands-slim.json)도 별칭을 싣고 초성 검색도 별칭을 훑으므로
   검색 이득은 그대로 얻고 화면은 안 망가진다.
   실증: `앤스로픽` 으로 검색하면 Anthropic 이 나오고 표시는 그대로 "Anthropic".

## SVG 우선 원칙 확정 (사용자 지시)

**SVG가 원본이고 PNG는 언제든 파생할 수 있다. 반대는 안 된다.**

| 상황 | 처리 |
|---|---|
| PNG만 있는 **보유 브랜드** | 서비스는 하되 `svg-wanted.json` |
| PNG만 있는 **미보유 후보** | **서비스 금지.** `collect-wanted.json` 만 |
| 비트맵이 박힌 SVG | SVG로 안 친다. 내리고 대기 목록 |

위키데이터 PNG-only 한국 브랜드 326건을 대기 목록에 넣었다(QID·파일명 포함).

## 3차 — 자동화 연결 + 고장 3종을 검사로 승격

수집기를 붙이기만 하면 오늘 찾은 함정이 **매일 재생산**된다. 파이프라인이
스스로 막게 만드는 게 핵심이었다.

`check-assets.py` 에 승격한 것 (전부 오늘 실제로 터진 것):
| 검사 | 안 잡으면 |
|---|---|
| logo.svg 는 있는데 logo.png 없음 | PNG 다운로드가 404 (신규 231개 전부 그랬다) |
| 비트맵이 박힌 SVG 를 벡터로 표시 | "확대해도 깨짐 없음" 이 거짓말 |
| 변형 매니페스트가 없는 파일을 가리킴 | 눌러도 안 받아지는 SVG 버튼 |
| **대소문자만 다른 중복 id** | 대문자 쪽은 CDN 404 (경고 → 실패로 승격) |

안내하는 복구 명령이 실제로 도는지도 확인했다 — logo.png 를 일부러 지우고,
검사가 잡고, `ensure-logo-png.py` 로 고쳐지고, 다시 통과하는 것까지.

**첫 CI 실행이 바로 진짜 버그를 잡았다.** `daisyUI` 는 **파일이 하나도 없는 채로**
브랜드만 등록돼 있었고(2026-08-06 생성) CDN 404 였다. 열흘간 아무도 몰랐다.
맥은 대소문자를 구분하지 않아 로컬에서는 `daisyui` 와 한 폴더로 보인다.

### ⚠️ `git rm -r` 이 원본까지 지운다
`git rm -r _clients/macOS` 를 쓰니 맥에서는 같은 파일이라 **소문자 원본
`macos/logo.svg` 까지 디스크에서 날아갔다.** `git checkout` 으로 되살렸다.
인덱스에서만 빼야 한다 — `git rm --cached --sparse`.

### 커밋 단계에 있던 구멍
워크플로가 커밋할 파일을 하나하나 나열하고 있어서 **새 브랜드 폴더가 통째로
빠질** 상태였다. brands.json 만 올라가고 로고는 CDN 에 없는 — 신규 브랜드
전부 404 가 날 뻔했다. `_clients` 를 통째로 담도록 고쳤다.

워크플로와 같은 순서로 로컬 리허설 → 실제 CI 2회 실행 → 전 단계 success 확인.
