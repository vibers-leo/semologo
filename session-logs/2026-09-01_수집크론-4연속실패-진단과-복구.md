# 수집 크론 4연속 실패 — 진단과 복구

크론이 4회 연속 실패하고 3~4시간씩 돌다 죽고 있었다. 원인이 셋이었다.

## ① Illustrator SVG 435건이 렌더 실패

cairosvg 는 defusedxml 로 파싱하는데 그게 **모든** 엔티티 선언을 거부한다
(EntitiesForbidden). 그런데 Adobe Illustrator 가 내보낸 SVG 는 거의 항상
이렇게 생겼다:

```xml
<!DOCTYPE svg [ <!ENTITY ns_svg "http://www.w3.org/2000/svg"> ]>
<svg xmlns="&ns_svg;">
```

실제 위험(XXE)이 아니라 네임스페이스 별칭인데 파생물을 통째로 못 만들었다.

`unsafe=True` 로 푸는 건 답이 아니다 — 외부 엔티티까지 열려 신뢰할 수 없는
SVG(위키미디어·웹 수집분)에 XXE 를 허용하게 된다.
**내부 선언만 값으로 치환하고 DOCTYPE 을 지운다.**

### 엔티티 다음으로 흔한 것 — SVG 자체의 오작성

315건이 살아난 뒤에도 120건이 남았고, 패턴이 뚜렷했다:

| 오작성 | 원인 |
|---|---|
| `stroke-opacity="null"` `opacity="undefined"` | JS 로 만든 SVG |
| `letter-spacing="-0.2r"` | rem 단위를 잘라먹음 |
| `fill="rgb(65 74 71)"` | CSS Color 4 공백 구분 — cairosvg 미지원 |
| `xmlns` 누락 | unbound prefix 로 죽는다 |

`sanitize()` 로 넷을 고쳐 **91건이 더 복구**(120 → 29).
남은 29건은 시간 초과 13 · 크기 초과 6 · 진짜 깨진 것 10.

**총 435건 중 406건 복구.** 렌더 결과는 시트로 눈검사했다.

# 2부 — '기타' 정리 (5,871 → 4,740)

## 규칙이 부족한 게 아니라 **있던 규칙이 안 먹고 있었다**

```
financial technolog\b   → 'financial technology' 미매칭 (뒤에 y)
\bpharmaceutic\b        → 'pharmaceutical company' 미매칭 (뒤에 al)
manufactur(er|ing)␣     → 'manufacturer of X' 미매칭 (뒤에 of)
real estate             → 'real-estate company' 미매칭 (하이픈)
```

**`\b` 함정을 하루에 세 번 밟았다.** 에러가 안 나고 조용히 매칭만 실패하므로
눈치채기 어렵다. 어근은 `\w*` 로 열고 완전한 단어에만 `\b` 를 쓴다.
하이픈 표기도 함께 받는다.

이 수정 하나로 **976건**이 살아났다.

# 3부 — 공식 CI 원본 등록 (부산광역시 · 청년작당소)

배포처가 준 `.ai` 원본을 **벡터 무손실로** 등록했다.

## `.ai` 는 PDF 다

Illustrator 파일은 PDF 호환으로 저장돼 있어 `pdftocairo -svg` 로
벡터 그대로 변환된다. 두 가지 경우가 있었다.

| 자료 | 방법 |
|---|---|
| 부산 — 종류별로 파일이 나뉨 | 파일마다 `pdftocairo -svg` |
| 청년작당소 — 21p 매뉴얼 한 파일 | 페이지를 SVG 로 만든 뒤 **viewBox 만 교체**해 영역 크롭 |

두 번째가 특히 쓸모 있다. 경로를 손대지 않으므로 무손실이고,
한 페이지에 여러 변형이 배치된 매뉴얼에 그대로 쓸 수 있다.

```python
s = re.sub(r'(<svg[^>]*?)width="[^"]*"\s*height="[^"]*"\s*viewBox="[^"]*"',
           lambda m: f'{m.group(1)}width="{w}pt" height="{h}pt" '
                     f'viewBox="{x0} {y0} {w} {h}"', svg, count=1)
```

## 등록 결과

```
부산광역시     4종  국문·심벌마크·국영문·영문 시그니처
청년작당소     7종  가로 A/B · 세로 A/B · 워드마크 · ㅊ심볼 · 그래픽 모티브
```

파비콘은 조합형을 욱여넣지 않고 **심벌 한 덩어리**로 만들었다
(부산=심벌마크, 청년작당소=ㅊ 도형). 64px 에서도 형태가 산다.

## 함정 네 개

**① cairosvg 가 부산 SVG 를 못 그린다**
변환 결과에 `<filter>` 가 있어 **검은 사각형**을 뱉는다(불투명 1.000).
브라우저는 그라데이션까지 정상이므로 SVG 자체는 멀쩡하다 — 렌더러 한계다.
그래서 PNG 파생물은 SVG 가 아니라 **원본 .ai 에서 직접** 뽑았다.

**② override 가 무시되고 있었다**
`build-logo-variants.py` 의 override 처리가 `if not candidates:` 안에 있어
**logo.svg 가 있으면 사람이 쓴 변형이 통째로 무시**됐다. 부산은 SVG 렌더가
실패했는데도 그 '분석 불가' 결과가 4종을 덮어썼다.
docstring 은 "origin=manual 은 절대 덮어쓰지 않는다"인데 코드가 달랐다.

**③ 영역 좌표를 유채색만으로 잡으면 텍스트가 빠진다**
'가로형 B' 에서 '청년작당소' 글자가 통째로 잘렸다. 설명문 영역(상단·하단)을
제외하고 **무채색까지 포함**해 잡아야 한다.

**④ 매뉴얼 원본이 CDN 404 였다**
버킷 동기화 확장자 목록에 `.ai` 가 없었다. `.ai` 는 실제로 PDF 라
`application/pdf` 로 내보내야 브라우저가 열어 준다.
`.pdf`·`.zip`·`.eps` 도 함께 받게 했다.

파일이 있어도 화면에 링크가 없어 `brand_manual` 필드를 두고
'공식 배포 원본' 배지 옆에 📘 버튼을 붙였다. 매뉴얼에는 컬러 팔레트·
최소규격·응용례가 들어 있어 **로고 파일만큼 값어치가 있다.**
