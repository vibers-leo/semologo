# 2026-08-02 — 세모로고 프로젝트 초기 세팅 및 Vercel 배포

## 세션 개요
- 프로젝트: 세모로고 (SemoLogo) — 세상 모든 로고
- 핵심 결과: Next.js 프로젝트 생성 → GitHub 푸시 → Vercel 배포 → semo.vibers.co.kr HTTP 200 확인

## 주요 작업

### Phase 1: GitHub 레포 + Next.js 프로젝트 생성
- `gh repo create vibers-leo/semologo --public` 으로 레포 생성
- `bun create next-app semologo --typescript --tailwind --app --src-dir --no-eslint` 로 프로젝트 생성
- `bash new-app-symlink.sh semologo` 로 외장SSD 심링크 생성
- git init + remote 연결

### Phase 2: 핵심 파일 작성
- `src/lib/firebase.ts` — ai-recipe-lab Firebase 재사용, typeof window guard 추가
- `src/lib/brands.ts` — brands.json CDN fetch (logo.vibers.co.kr/_clients)
- `src/components/Header.tsx` — 검색바 + 네비게이션
- `src/components/BrandGrid.tsx` — 카드 그리드 + 카테고리 필터 + 최신순 정렬
- `src/components/BrandModal.tsx` — SVG/PNG 다운로드 모달 (한글/영문 병기 지원)
- `src/app/login/page.tsx` — Google OAuth 로그인
- `src/app/robots.ts` + `src/app/sitemap.ts` — SEO

### Phase 3: 배포 트러블슈팅
**문제 1: Turbopack 심링크 이슈**
- 원인: Next.js 16은 Turbopack만 지원, 외장SSD 심링크 처리 불가
- 해결: 로컬 빌드 포기, GitHub push → Vercel 서버 빌드로 전환

**문제 2: Firebase auth/invalid-api-key**
- 원인: `vercel deploy` (preview 환경)에 env vars가 production 전용으로만 등록
- 해결: Preview 환경에도 동일 env vars 추가

**문제 3: sitemap.xml 빌드 실패**
- 원인: `brands.json` fetch 결과가 배열이 아닐 때 `.map()` 오류
- 해결: `Array.isArray()` guard 추가, fetchBrands 에러 핸들링

### Phase 4: 도메인 연결
- `vercel domains add semo.vibers.co.kr semologo`
- Cloudflare에 CNAME 추가: `semo → a33761303d002794.vercel-dns-016.com` (프록시 OFF)
- DNS 즉시 전파 확인, HTTP 200 검증
