# 국내 수집 확장 — 상장사·프랜차이즈·공공기관

국내 브랜드가 전체의 3.8%(1,631개)뿐이었고 그마저 공공 편향이었다.
한국 사용자가 실제로 검색할 민간 브랜드가 거의 없었다.

```
국내 1,631 → 2,239  (상장사 394 · 공공기관 165 · 프랜차이즈 43)
```

## 네이버 API 허브 — 홈페이지가 없으면 찾는다

명단에 홈페이지가 비어 있는 것이 수집 실패의 절반(no_site 47%)이었다.

⚠️ **검색 1등을 믿으면 안 된다.** `닷밀 → jobplanet`(구인사이트) 오답이 났다.
   판정 기준은 **실제 접속해 회사명이 페이지에 있는지** 하나뿐이다.
   반복 횟수·검색 순위는 참고일 뿐이다.

   처음엔 '반복 2회 이상'만 채택했는데 **정답을 대부분 버렸다** —
   naraspace.com·thepinkfongcompany.com·g2gbio.com 이 모두 1회라 탈락했다.
   회사가 작을수록 검색 결과가 흩어진다.

스팩(기업인수목적회사)은 껍데기라 홈페이지도 로고도 없다 — 39%를 아예 제외했다.

```
상장사     177건 중 85건 확보 (79%)
프랜차이즈   916건 확보 (진행 중)
```

## 정적 HTML 로는 42%가 no_logo — 브라우저 렌더가 답이었다

원인이 넷이었다:

```
니어스랩    img 0개        JS 로 그리는 SPA
기도산업    alt 전부 빈 값   웹접근성 미준수
딜리셔스    inline-svg 17  로고가 <svg> 로 직접 그려져 있다
케이피항공   css-bg         CSS background-image
```

`collect-krx-rendered.py` — 브라우저로 띄운 뒤 DOM 에서 찾는다.
헤더 안·화면 상단·홈으로 가는 링크를 우선한다. **0% → 83~87%**.
`--source krx|gov|franchise` 로 명단만 갈아 끼운다. 가드는 collect-krx 의 것을
그대로 쓴다 — 두 벌로 갈리면 한쪽만 고쳐진다.

두 가지 접속 실패도 처리했다:
- `ERR_NAME_NOT_RESOLVED` — www 를 떼거나 https 로 바꿔 재시도
- `interrupted by another navigation` — 사이트가 스스로 리다이렉트하는 것이라
  실패가 아니다. 무시하고 렌더 결과를 읽는다

## 파이프라인 결함 6개

이번 작업의 진짜 수확이다 — 앞으로 들어올 모든 브랜드에 적용된다.

```
① 수집기가 KRX 원본을 매번 새로 받아 보강한 홈페이지를 무시
② logo-800 을 SVG 있을 때만 생성 → PNG 전용 브랜드가 404       (10/21)
③ 흰 로고에 remove_white_bg → 투명본이 빈 파일                 (3/21)
④ 파비콘 폴백이 make_icon 직행 → 백지                          (3/21)
⑤ '흰색 전용' 거부 → 다크용 흰 로고는 정상인데 버림
⑥ min(size)<40 → 가로형 로고(198x24)가 탈락
```

②③④는 신규 21건 중 **16건에 영향**을 줬다. 안 고치고 1,450개를 수집했으면
절반 이상이 깨진 파생물을 가졌을 것이다.

`light_logo` 플래그는 별도 스크립트가 붙이는데 신규 수집분은 그게 아직 안 돈다.
**잉크가 전부 순백이면 그 자리에서 밝은 로고로 판정**하게 했다.

## ⚠️ brands.json 이 통째로 덮어써져 25건이 사라졌다

프랜차이즈 수집이 **시작할 때 읽은 스냅샷**에 덧붙여 저장하면서, 그 사이
등록된 공공기관을 지웠다. 폴더와 이미지는 남았는데 '어느 브랜드인지'를 몰라
복구가 막혔다 — **홈페이지 주소가 없었기 때문이다.**

두 겹으로 막았다:
1. `_source.json` 을 폴더마다 남긴다(홈페이지·출처·수집시각·로고 URL).
   목록이 깨져도 폴더만으로 되살릴 수 있다. 기존 39,811건에 소급 기록.
2. 저장 직전에 **brands.json 을 다시 읽어 병합**한다. 동시 실행해도 안 잃는다.

유실 27건은 명단 대조로 복구했다.

구분이 안 돼 오탐만 났다. 원형 배지 1건만 프로그램이 잡았다.
