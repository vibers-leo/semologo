## 배운 것 / 함정

**게이트 임계값은 전부 실측으로 정했다.** 오분리를 눈으로 보며 세 번 조였다.
- `Gmarket→'rket'` → 조각 세그먼트 수 규칙
- `arm→'a'` → 나머지 덩어리 수 규칙
- `airbus→'AI'` → 조각 1덩어리 규칙
- 우측 조각 시도는 표본 3건 전부 오분리라 폐기

**세로 분리는 자동화하지 않았다.** 표본 489개 중 새로 분리되는 건 7개(1%)인데
5개가 오분리였다(심볼 반토막). 이득 1%로는 위험을 감수할 이유가 없어
사람이 확인한 건만 `variants.override.json` 으로 등록하는 방식으로 갔다.

**brand-logos 에 version.txt 자동 갱신 pre-commit 훅이 있다.** 그래서
semologo VERSION 을 먼저 맞추면 반드시 어긋난다. brand-logos 를 먼저 푸시하고
`curl https://logo.vibers.co.kr/version.txt` 로 최종값을 읽어 넣어야 한다.

## 후속 (같은 날) — 남은 3단계 + 빈 카드

### 빈 카드의 진짜 원인
사용자가 "아무것도 없는 빈 카드"를 보고했다. 데이터에는 로고 없는 브랜드가
0건이었고, 원인은 두 가지였다.

1. **미노출 AdSense 슬롯** — `minHeight:90px` 로 자리를 잡아둬서 광고가 안
   채워져도 90~102px 빈 띠가 남았다. 실측 결과 슬롯 7개 전부 미노출.
   12개 카드마다 하나씩 생겨 빈 카드처럼 보였다.
   → `data-ad-status` 를 관찰해 스스로 접게 했다.
   **주의:** `offsetHeight` 로 판단하면 안 된다. AdSense 는 채울지 정하기
   **전에** 먼저 90px 자리를 잡아서, 높이로 보면 미노출인데 '채워짐'으로
   오판한다. 처음에 그렇게 만들었다가 그대로 남아 있는 걸 실측으로 잡았다.

2. **밝은 로고** — 흰색 로고가 밝은 카드 배경에서 안 보였다.
   처음엔 매니페스트 `color=mono-light` 로 13개만 잡혔는데, 채도로 판정하면
   '컬러 아이콘 + 흰 글자' 조합을 놓친다. logo.svg 를 투명 렌더해 잉크의
   40% 이상이 luma>235 인지 재니 **82개**가 나왔다.
   `logo-transparent.png` 로는 판정 불가 — 그 파일은 흰색을 이미 제거했다.

### B. 중복 통합 — 429쌍
`-icon` 브랜드를 부모의 심볼 변형으로 흡수. **삭제하지 않았다** — 지우면
정적 페이지 429개가 404 가 된다. `variant_of` 로 표시해 목록·사이트맵에서만
빼고, 페이지는 살린 채 canonical 을 부모로 돌렸다.
목록 노출 6,822 → 6,393.

이 과정에서 중복 카드가 다시 생기는 걸 발견해 그룹핑을 고쳤다:
- 슬러그가 `-icon` 이면 종횡비보다 우선 (YouTube 재생버튼이 가로로 넓어
  'horizontal' 로 분류돼 본체와 합쳐지던 문제)
- 그룹 키에서 색상 제거 — 제공자별 색상 차이로 `airbnb` 에 '심볼형' 카드가
  3장씩 떴다. 형태로 묶고 알려진 언어가 2개 이상일 때만 언어로 분리.
