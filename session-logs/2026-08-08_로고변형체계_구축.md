- `scripts/logoform.py` 신규 — 형태 분석·심볼 분리 라이브러리
  - 래스터로 심볼 위치를 찾고 **viewBox 만 교체**해 무손실 벡터 크롭

- 흰색 fill 로고가 흰 배경 렌더 + 흰색 제거로 **파비콘이 백지가 되던 버그** 수정

- 깨지는 다운로드 버튼 10,654개 → 531개 (31% → 1.6%, UI가 숨겨 노출 0)

## 배운 것 / 함정

**게이트 임계값은 전부 실측으로 정했다.** 오분리를 눈으로 보며 세 번 조였다.
- `Gmarket→'rket'` → 조각 세그먼트 수 규칙
- `arm→'a'` → 나머지 덩어리 수 규칙
- `airbus→'AI'` → 조각 1덩어리 규칙
- 우측 조각 시도는 표본 3건 전부 오분리라 폐기

**세로 분리는 자동화하지 않았다.** 표본 489개 중 새로 분리되는 건 7개(1%)인데
5개가 오분리였다(심볼 반토막). 이득 1%로는 위험을 감수할 이유가 없어
사람이 확인한 건만 `variants.override.json` 으로 등록하는 방식으로 갔다.

**brand-logos 에 version.txt 자동 갱신 pre-commit 훅이 있다.** 그래서
semologo VERSION 을 먼저 맞추면 반드시 어긋난다. brand-logos 를 먼저 푸시하고
`curl https://logo.vibers.co.kr/version.txt` 로 최종값을 읽어 넣어야 한다.
