# 가공 아이콘 기능 — 2026-10-10

공식 원본/변형과 분리된 상세 섹션을 사용자가 펼치면 단색 벡터를 확인한다. 원본 경로와 fill-rule을 유지하고 흰색으로 편집한 뒤 원형 또는 사각형 배경을 더한다. 원본 로고에서 읽은 색 또는 사용자가 직접 선택한 색을 쓰며, 자동으로 브랜드색을 지어내지 않는다. 전체가 흰색인 원본은 사용자가 배경색을 정해야 생성할 수 있다.

결과는 모두 `가공 아이콘`, `공식 제공 파일 아님`으로 표시한다. SVG는 실제 벡터, PNG는 1024×1024다. 브랜드명을 대신 쓰는 문자/이니셜 placeholder는 만들지 않는다. 다색, 이미지 포함 SVG, 외부 참조, CSS/스크립트, 텍스트, 가이드처럼 원본 형상을 손상할 가능성이 있는 자산은 거절한다. 단색 제약은 원래 그림 안의 흰색과 실제 구멍을 무작정 합쳐버리는 일을 막는다.

서버는 ID로 현재 공개 CMS/검수 자산을 찾고 고정 CDN 또는 등록 submissions 경로만 읽는다. 사용자 URL/파일경로를 받지 않는다. 입력 500KB 제한, fetch 시간 제한, 동시 작업 3개, 캐시 64개, 정적 SVG 태그/속성 허용 목록과 숫자 범위 검사를 적용한다. SVG에는 sandbox CSP를 준다. 다운로드는 성공한 image MIME만 받아 기존 다운로드 통계 경로에 전달한다.

검증: `bash scripts/with-local-storage.sh node --experimental-strip-types scripts/check-processed-logo-icons.mjs`. 악성 SVG, entity, 외부/내장 SVG 참조, 이벤트, foreignObject, 다색, 텍스트, 중복 속성 차단과 1024 렌더/ㅁ 내부 공간 보존을 검사한다. 배달의민족 예시는 사용자 선택 민트 배경이며 공식 제공 아이콘으로 표시하지 않는다.
