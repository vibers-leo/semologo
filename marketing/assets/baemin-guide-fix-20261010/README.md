# 배달의민족 / 배민라이더스 ㅁ 경로 수정 — 2026-10-10

앞선 PDF drawing 재구성에서 폐곡선 내부의 move-to/close-path 경계를 잃어 '민'의 ㅁ 안쪽 공간이 채워졌다. SVG를 비트맵으로 대체하지 않고, 원본 PDF에서 내보낸 SVG의 d/fill-rule/transform을 그대로 복사한다. 페이지 9/10/17의 로고만 경계 상자로 선택하고 viewBox만 줄였으며, 경로를 다시 연결하거나 도형을 다시 그리지 않는다.

5개 SVG와 2000px 긴 변 PNG 5개를 새 immutable 경로에 생성했다. 이전 앱 아이콘 PNG, 캐릭터 PNG, 원본 PDF 참조와 명칭·별칭·관련 콘텐츠·대표 배경 메타데이터는 유지했다. 가이드 날짜는 2019.01.04이며, 형상 교정만으로 공개 날짜를 변경하지 않았다.

검증: 원본 PDF 해당 영역의 8배 렌더와 이전 PNG / 수정 PNG를 비교했다. 폭 1600에 정규화하고 서로 다른 PDF/SVG 래스터라이저의 2픽셀 경계 오차를 허용한 형상 불일치율을 geometry-proof.json에 기록했다. 라이더스는 원 안쪽 흰 글자까지 검증하도록 민트 색상 마스크를 사용했다. 기존 불일치율 0.51~1.99%가 수정 후 0~0.0064%로 감소했다. 모든 비교 및 확대 연락 시트를 눈으로 확인했고 '민'의 ㅁ 내부가 원본과 일치한다.
