# PNG 전용 등록분 공식 벡터 재수집

- 요청 범위: 후쿠이제작소~보령베이스, 등록 순번 182299~180522, 1,778건.
- CMS 이전 상태: `cms-before.json` (로컬 백업, 비공개 운영 상태 복구용).
- 전체 대상과 공식 페이지 매칭: `queue.json`; 기존 공식 페이지 1,627건.
- 수집: `bash scripts/with-local-storage.sh python3 scripts/recollect-png-official-20261010.py`
- 중단 후 같은 명령으로 미처리 항목만 재개한다. `results.json`과 `progress.json`은 매 10건마다 원자적으로 저장한다.
- 다운로드 성공은 게시 승인과 다르다. 기관 동일성, 실제 벡터 여부, 가이드 제거, 투명/흰색 artwork 보존, PNG 렌더링을 시각 검수한 후 별도 release로 게시한다.
- AI/ZIP 원본을 보관하며 래스터를 SVG로 감싸 벡터라고 표시하지 않는다.
- 기존 콘텐츠 ID와 주소는 유지한다. 배경 수정만으로 최신순 공개일을 올리지 않는다.

1차 공식 페이지 점검 완료: 1,778건 중 626건에 다운로드 후보가 있음. 이 수치는 실제 AI/SVG 확보·시각 검수·게시 완료 수와 다르다. 초기 검수 게시: 공식 SVG 19기관 36종, 공식 AI 6기관 17종.
