# MCP 공개 — 캠페인 노트 (2026-08)

## 무엇이 새로운가

`npx semologo-mcp` 한 줄이면 Claude Code·Cursor 안에서 **대화 중에** 로고를 가져온다.
검색창을 열고, 받고, 이름 바꾸고, 폴더에 옮기는 단계가 통째로 사라진다.

```
"헤더에 스타벅스랑 카카오 로고 넣어줘"
  → AI 가 알아서 찾아서 SVG 를 코드에 삽입
```

## 왜 이게 남다른가 (= 우리가 말할 것)

| | 세모로고 MCP |
|---|---|
| **한국 브랜드** | 6,800여 개. 삼성·카카오·농협·기업은행이 전부 있다 |
| **한글·초성 검색** | `ㅅㅅ` → 삼성. 글로벌 서비스가 못 하는 지점 |
| **가입·키 없음** | 설치하면 바로 됨. 사용량 제한도 없다 |
| **비용 0** | 사용자 PC 에서 돌고 CDN 만 읽는다 |

경쟁 서비스는 대부분 해외 브랜드 위주고, 한국 브랜드를 **한글로** 찾는 건 우리뿐이다.
"세모로고 = 한국 로고" 라는 자리를 잡는 게 이 캠페인의 목적이다.

## 후원 흐름 (강요하지 않는다)

로고를 **실제로 받은 직후** 한 번만 SVG 주석으로 안내한다:

```
<!-- 세모로고는 광고와 후원으로 굴러갑니다. 도움이 되셨다면 커피 한 잔 ☕ -->
```

키·가입을 요구하지 않는 이유는 `mcp/README.md` 와 커밋 메시지에 남겼다.
요약하면 — CDN 이 공개라 키를 걸어도 우회되고, 정직한 사람만 불편해진다.
그리고 키를 넣는 순간 "항상 살아 있어야 하는 서버" 가 생긴다.
