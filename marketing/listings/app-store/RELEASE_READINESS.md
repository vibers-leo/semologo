# 세모로고 스토어 출시 준비도

최종 점검: 2026-10-11. **스토어 등록·심사 제출 미완료.**

## 준비된 항목

- `native/`에 Capacitor 8 iOS·Android 플랫폼 프로젝트 생성 완료.
- 로컬 번들 검색, 상세 바텀시트, 기기 저장 목록, PNG OS 저장·공유, 브랜드 링크 공유 구현.
- 22개 모듈의 브라우저 번들 생성 완료. 안전성 테스트 2개 통과.
- 기존 세모로고 1024px 아이콘 확인. iOS 아이콘 교체, Android 리소스 생성 진행.
- iOS PrivacyInfo.xcprivacy를 앱 Resources에 포함했고 plist 문법 검사 통과.
- 개인정보처리방침·이용약관 버튼 추가. 앱의 목록은 기기에 저장되며 서버 회원 즐겨찾기와 별개.

## 진행 중

- Android 설치용 debug 빌드: 최초 Gradle 도구 다운로드 중.
- iOS 시뮬레이터 debug 빌드: 서명 없이 빌드 진행 중.
- 플랫폼에 최신 웹 번들 동기화 진행 중. 빌드 성공·실행·다운로드·OS 공유 검증 전에는 설치 가능 또는 심사 준비 완료로 표시하지 않음.

## 제출에 필요한 항목

- 개발용 임시 ID `com.example.semologo.dev`를 실제 소유 출시 ID로 확정하고 계정·서명 팀·키 확인.
- 실제 앱 실행 검수와 해당 기기의 스크린샷, 스토어 개인정보·연령등급 답변.
- 네이티브 로그인은 아직 구현하지 않음. 웹 로그인과 구분. 계정 기능을 추가하면 로그인 대안·계정 삭제 흐름까지 검증.
- Universal Links/App Links의 실제 도메인·서명 연결은 미완료.
- 서명 release 빌드, TestFlight/Play 내부 테스트, 콘솔 업로드와 심사 제출.

## 콘솔 접근 상태

2026-10-11 작업 중 App Store Connect와 Google Play Console 열기가 CUA 브라우저의 보안 정책 검증 실패로 거절됨. 다른 접근 방식으로 우회하지 않았으며 콘솔 등록·업로드는 수행하지 않음.

앱 이름 초안: 세모로고. 부제: 세상 모든 로고를 한곳에. 운영 법인: 주식회사 계발자들. 로고 권리는 각 브랜드에 있음.
