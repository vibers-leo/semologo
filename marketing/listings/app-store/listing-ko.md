# App Store 등록 문안 초안

## 기본 정보

- 앱 이름: 세모로고
- 부제: 세상 모든 로고를 한곳에
- 카테고리 후보: 그래픽 및 디자인
- 저작권: 2026 주식회사 계발자들

## 설명

세모로고는 필요한 브랜드 로고를 검색하고, 내 기기에 저장하거나 다른 앱으로 공유할 수 있는 로고 라이브러리예요.

- 브랜드 이름으로 로고를 검색하고 더 많은 결과를 이어서 확인해요.
- 자주 쓰는 브랜드를 내 기기에 저장해요.
- PNG를 기기의 공유 화면에서 파일로 저장하거나 다른 앱으로 보내요.
- 브랜드 페이지 링크를 공유해요.
- 전체 로고 구성은 브라우저에서 열어 준비된 SVG·PNG와 원본 파일을 확인해요.

기본 기능은 회원가입 없이 이용할 수 있어요. 기기에 저장한 목록은 웹 회원 계정과 동기화되지 않아요. 로고의 권리는 각 브랜드에 있으며, 사용할 때 해당 브랜드의 이용 조건을 확인해 주세요.

## 이번 웹 버전의 앱 반영 후보

- 로고월을 만들고 저장한 뒤 HTML로 재생·확대해서 확인해요.
- PNG 이미지와 웹 코드, JSON을 ZIP 한 파일로 내려받아요.
- 스포츠·방송·언론·대학 세트의 기준 시즌과 수집현황을 확인해요.
- 지원하는 단색 로고는 공식 원본과 구분된 가공 아이콘으로 내려받아요.

위 웹 기능은 네이티브 화면의 구현 기능으로 홍보하지 않습니다. 실제 설치·공유 검증과 출시 ID·서명 확인 후 문안을 확정하며, 현재는 제출하지 않은 초안입니다.
