# 세모로고 브랜드 자산 체계

## 기준 자산

| 용도 | 파일 | 규격 |
| --- | --- | --- |
| 가로형 로고 | `public/brand/semologo/logo-horizontal.png` | 1600×625 |
| 세로형 로고 | `public/brand/semologo/logo-vertical.png` | 1200×1200 |
| 앱 아이콘 원본 | `public/brand/semologo/app-icon-1024.png` | 1024×1024, 불투명 |
| 웹/PWA 아이콘 | `public/icon-192.png`, `public/icon-512.png`, `public/apple-touch-icon.png`, `src/app/favicon.ico` | 서비스 적용본 |
| 투명 심볼 마스터 | `marketing/assets/semologo-symbol-transparent.png` | 디자인 작업용, 스토어 업로드 금지 |

가로형은 **심볼 + 세모로고 워드마크 + 태그라인**, 세로형은 **심볼 위 / 워드마크 아래** 구성을 쓴다. 앱 아이콘·파비콘에는 심볼 단독만 쓴다.

## 수집 로고의 변형 원칙

1. 수집한 원본에 실제 SVG/AI/EPS가 있을 때만 벡터 파일로 제공한다.
2. `symbol`, `horizontal`, `vertical`, `wordmark`는 원본에 존재하거나 권리 보유자가 제공한 형태만 별도 변형으로 등록한다.
3. 단일 심볼 SVG에 브랜드명을 임의 조합해 공식 로고처럼 만들지 않는다. 브랜드 서체·여백·상표 사용 규칙을 알 수 없기 때문이다.
4. 세모로고처럼 권리 보유자가 직접 승인한 자사 브랜드만 이 문서의 가로형·세로형 조합 규칙으로 파생할 수 있다.
5. 앱 아이콘은 1024×1024 PNG, 불투명 배경, 텍스트 없는 심볼 단독을 기준으로 한다. 파비콘·PWA 아이콘은 이 원본에서 축소한다.
