제목: **세모로고 MCP — AI에게 말하면 한국 브랜드 로고를 코드에 넣어줍니다**

> 로고 하나 넣으려고 검색하고, 받고, 이름 바꾸고, 폴더 옮기다 보면 흐름이 끊깁니다.
> 그 단계를 없애려고 만들었습니다.
>
> ```
> claude mcp add semologo -- npx -y semologo-mcp
> ```
>
> - 브랜드 6,800여 개 (한국 브랜드 위주)
> - 한글·초성 검색 — `ㅅㅅ` → 삼성, `엘지` → LG
> - SVG 원문을 그대로 반환해서 코드에 바로 들어갑니다
>
> **서버가 없습니다.** 사용자 PC에서 돌면서 공개 CDN을 읽을 뿐이라
> 가입·API 키·사용량 제한이 없고, 저희가 멈춰도 계속 동작합니다.
>
> 광고와 후원으로 굴러갑니다. 도움이 되셨다면 커피 한 잔 ☕

**댓글 대비** — 나올 만한 질문과 답:
- *"로고 저작권은?"* → 브랜드 로고는 각 사 소유. 우리는 위치를 안내할 뿐이고,
  사용 책임은 사용자에게 있다. 상표 사용 지침을 따르라고 안내한다.
- *"무료면 언제 유료화하나"* → 계획 없음. 원가가 사실상 0이라 유료화 이유가 없다.
- *"글로벌 브랜드는?"* → 있지만 강점은 한국 브랜드다. 솔직하게 말하는 게 낫다.
