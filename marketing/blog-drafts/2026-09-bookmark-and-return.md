# 초안 4. 로고별 저장 대신, 사이트를 다시 찾게 만드는 방법

## 한 줄 요약

콘텐츠별 즐겨찾기보다 사이트 자체를 브라우저에 저장하도록 안내하는 UX를 선택한 이유를 설명해요.

## 본문 초안

사용자가 원한 건 로고 파일마다 목록을 만드는 기능이 아니었어요. 다음에 로고를 찾으러 세모로고에 다시 방문할 수 있는 방법이었어요.

브라우저는 보안상 웹사이트가 사용자의 북마크를 강제로 추가할 수 없어요. 대신 헤더의 별표 버튼에서 Windows·Linux는 Ctrl+D, Mac은 Command+D, 모바일은 브라우저 메뉴와 홈 화면 추가 방법을 안내하도록 바꿨어요.

이 방식은 북마크 데이터를 서버로 보내지 않으면서도 재방문 경로를 분명하게 알려줘요. 사용자가 어떤 로고를 저장했는지 수집하지 않고, 사이트 자체를 기억하게 돕는 방식이에요.

## 키엔AI 다듬기 메모

- 브라우저별 안내를 아이콘과 함께 시각화해 주세요.
- “자동 저장”처럼 오해할 표현은 피해주세요.
- 영상 훅: “웹사이트가 여러분의 북마크를 대신 눌러줄 수 없는 이유.”
