# 세모로고 동반 글 템플릿

키엔AI 원문을 인용할 때 세모로고에 작성하는 독자적인 해설판입니다. 원문을 번역하거나 복사하지 말고, 실제 다운로드와 사용 맥락을 중심으로 새로 작성해요.

```yaml
title:
slug:
publishedAt:
canonicalUrl: https://semologo.com/blog/{slug}/
keyenaiSourceUrl:
summary:
downloadContext:
relatedBrandUrls: []
sourceUrls: []
```

본문은 다음 순서로 작성해요.

1. 세모로고 사용자가 이 주제를 찾는 이유
2. 원문에서 확인한 핵심 사실 1~2개와 키엔AI 링크
3. 세모로고에서 받을 수 있는 파일과 형식별 사용법
4. 관련 브랜드 페이지와 상표권 안내

원문과 다른 제목·소제목·문장·사례를 사용하고, 인용은 짧게 유지해요.
