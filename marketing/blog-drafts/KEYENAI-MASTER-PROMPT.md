# 키엔AI 세모로고 매거진 발행 마스터 프롬프트

아래 지침과 지정된 초안 파일을 읽고 세모로고 관련 매거진 원문을 작성·발행해 주세요.

## 먼저 읽을 파일

1. `marketing/blog-drafts/KEYENAI-PUBLISH.md`
2. `marketing/blog-drafts/README.md`
3. 발행할 `marketing/blog-drafts/2026-09-*.md`

## 역할과 목표

세모로고는 브랜드 로고를 검색하고 SVG·PNG 파일을 확인하는 서비스예요. 검색 유입을 늘리고, 디자이너·마케터·개발자가 로고를 올바르게 사용하는 데 도움이 되는 매거진을 발행해 주세요.

초안의 세션 날짜와 근거 커밋을 확인해 `publishedAt`을 정해 주세요. 초안에 기록된 `recommended_publish_date`가 있으면 그 날짜를 우선 사용해요.

## 문체

- 한국어 해요체
- 짧은 문단과 명확한 소제목
- 과장·낚시성 표현·확인되지 않은 일화 금지
- 독자가 바로 실행할 수 있는 설명과 예시 사용
- 상표권과 파일 라이선스를 혼동하지 않게 안내

## AI 수집 설명 원칙

AI는 공개 자료에서 후보를 찾고, 브랜드명·카테고리·파일 형식을 분류하며, SVG 유효성·투명 배경·중복 여부를 검사하는 보조 도구로 설명해 주세요. AI가 찾았다는 이유만으로 자동 공개하는 것처럼 쓰지 말고, 출처·품질·권리 확인과 최종 공개는 사람이 한다고 명시해요. 크롤링 우회, 프록시, 차단 회피, 비공개 API 같은 운영 세부사항은 쓰지 마세요.

## 원문과 세모로고 해설판

- 키엔AI에는 초안을 확장한 독립적인 매거진 원문을 발행해요.
- 세모로고에는 같은 본문을 복사하지 않고, 요약·다운로드 맥락·SVG/PNG/AI 차이·관련 브랜드 링크를 담은 해설판을 작성해요.
- 양쪽 글은 제목·소제목·첫 문단·사례를 다르게 해요.
- 양쪽 글에 서로의 정확한 URL을 한 번씩 연결해요.
- 세모로고 해설판은 자기 URL을 canonical로 사용해요.
- 인용은 핵심 사실만 짧게 하고 전체 글을 재게시하지 않아요.

## 사실·출처 검수

- 공식 브랜드·공공기관·원 저장소 자료를 우선 사용해요.
- 출처 URL은 실제 접속 가능한지 확인해요.
- 사실과 해석을 구분하고, 확인되지 않은 이야기는 추정으로 단정하지 않아요.
- 로고 상표권은 각 브랜드에 있으며, 상업적 사용 전 해당 브랜드 가이드라인을 확인한다고 안내해요.
