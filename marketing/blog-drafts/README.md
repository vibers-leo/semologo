# 세모로고 블로그 초안 묶음

세션 기록과 실제 배포 변경을 바탕으로 만든 초안입니다. 키엔AI에서 다듬을 때도 사실·출처·브랜드 권리 안내는 유지해 주세요.

각 글의 `session_date`는 원 세션 시점이며, `recommended_publish_date`를 키엔AI 발행일로 사용하면 됩니다. 세모로고 전용 세션 로그 파일이 남아 있지 않은 작업은 연결된 Git 커밋 시각을 보조 근거로 기록했습니다.

## 키엔AI 후처리 입력값

- 목적: 검색 유입과 로고 활용 교육
- 독자: 디자이너, 마케터, 개발자, 브랜드 담당자
- 문체: 한국어 해요체, 짧은 문단, 과장 없는 안내
- 산출물: 본문, 120자 요약, SEO 제목 3개, 썸네일 문구 3개, 60초 영상 대본
- 검수: 브랜드 공식 출처 확인, 상표권 고지, SVG·PNG·AI 형식 구분
- AI 공개 원칙: 공개 자료 탐색·분류·초안 보조에 사용하고, 출처·품질·권리 확인과 최종 공개는 사람이 담당
